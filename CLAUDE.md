## Что это
Flutter-приложение (Android-планшет, альбомная ориентация) — пульт охранной
системы ZHURIN ELECTRONICS. Планшет по BLE подключается к концентратору
(например `BT485_EE2D`), тот ретранслирует пакеты LoRa-извещателей
L50RA / L60RA / L70RA / V10RA. Целевой дизайн — [design.md](design.md).
Язык интерфейса и комментариев — русский.

## Структура `lib/`
- `main.dart` — провайдеры; маршрут первого запуска: язык → пин-код → MainScreen.
- `providers/receiver_provider.dart` — вся логика: BLE (подключение,
  автопереподключение, состояние адаптера), разбор пакетов, программирование
  извещателей, охрана, журнал, батарея планшета, заводской сброс.
- `providers/settings_provider.dart` — тема, шрифт, язык, пин-код, основное BT-устройство.
- `services/database_service.dart` — sqflite (`alarm_receiver.db`, версия схемы 8),
  таблицы `detectors`, `events`, `settings` (key/value), `zones` (устаревшая).
- `services/api_sync_service.dart` — отправка журнала на сервер (очередь synced=0, пакеты, повторы).
- `services/app_foreground.dart` + `android/.../MainActivity.kt` — всплытие на передний план при тревоге (SYSTEM_ALERT_WINDOW).
- `services/audio_service.dart` — сирена, предупреждение, короткий сигнал.
- `screens/` — main (сетка блоков), settings, programming (программирование
  извещателей), onboarding (язык, пин-код), events, stats, help и др.
- `models/` — DetectorModel, EventModel.

## Серверное API (`server_api/`)
PHP 8.1+, mysqli, JSON, Bearer-токен. Документация — `server_api/README.md`.
Веб-панель управления планшетами — `public/admin.php` (вход администратора по хэшу из config.php).
Формат события = поля EventModel + `detectorSlot`, `zoneName`, `place`; `type` — имя
EventType строкой. Новый EventType нужно добавить и в `EVENT_TYPES` (`server_api/src/handlers.php`).
Клиент для смартфона — отдельный проект `../api_monitor` (ZH Монитор, читает `GET /events`);
новый тип события добавить и в его `lib/models/journal_event.dart` (`EventKind.all`).

## Протокол (6 байт, лишнее отбрасывается)
`[0-1] ID (hex "0001") · [2] канал = 0xAA · [3] код события · [4] 0x33 · [5] тип узла`
- Тип: 0x71 L50RA, 0x72 L60RA, 0x73 L70RA, 0x74 V10RA.
- Коды: 0x54 инициализация (программирование), 0x55 тревога, 0x58 вскрытие,
  0xA8 разряд, 0xAB выкл, 0xA9 вкл, 0xAA контроль, 0xAC напряжение, 0xA4 чувствительность.
- Характеристика событий определяется по содержимому пакета, не по UUID.

## Ключевые правила поведения
- Реагируем только на извещатели, которые есть в БД. 0x54 обрабатывается только
  в режиме программирования.
- У извещателя постоянный номер `slot` (номер квадрата), он назначается при
  программировании, а удаление номер освобождает без сдвига остальных.
- Тревога в течение 1 минуты после инициализации (0x54) игнорируется.
- Зона и место редактируются только на экране программирования (не на главном).
- Подпись в журнале — `_detectorLabel`: `№N МОДЕЛЬ [ID] Зона, место`.
- Тревога: дубли в течение 10 с от того же извещателя игнорируются (от других — нет); от снятого
  с охраны — полностью игнорируется (без звука, индикации, журнала).
- BT: при запуске и каждые 10 с без связи — `_tryReconnect`: с сохранённым id попеременно прямое
  подключение и поиск по id; без id — поиск по имени и запоминание. id в `settings.primaryDeviceId`,
  автопереподключение (кроме ручного отключения до нажатия
  «Подключиться»). В журнал пишутся: подключение, потеря связи (+ короткий
  сигнал), ручное отключение, выключение/включение Bluetooth планшета.
- Журнал: низкий заряд планшета (пороги 20% и 10%, без зарядки), переход на аккумулятор и возврат сети.
- Потеря BT: кнопка «СВЯЗЬ» красная, сигнал каждые 10 с; на аккумуляторе — сигнал раз в минуту.
- Пин-код хранится в `settings.pinCode` (открытым текстом), нужен только для
  заводского сброса; сброс очищает всю БД и возвращает к выбору языка.

## Интерфейс
- Все шрифты — через базовую величину `kBaseFontScale` (app_theme.dart, сейчас 2.0),
  применяется глобально в MaterialApp.builder. Новые fontSize пишем в «исходных»
  единицах; размеры контейнеров и иконок закладываем с учётом множителя.
- Верхняя строка: слева логотип и дата/время; справа ВКЛ/ВЫКЛ ВСЕ (`armState`: все — зелёная, никто — красная «ВЫКЛ ВСЕ», часть — серая), питание, СВЯЗЬ, ЗВУК, справка и настройки.
- Нижняя строка: связь, число извещателей, ТРЕВОГА/ОХРАНА, кнопки зон (по `zoneName`, `setZoneArmed`).
- Масштаб шрифта в настройках 50–150%, умножается на kBaseFontScale.
- Пин-код требуется для: выключения звука, добавления и удаления извещателя,
  заводского сброса (`showPinCheckDialog`).
- Извещатели в покое на связь не выходят, понятия «нет связи с извещателем» нет.
