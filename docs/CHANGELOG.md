## 2026-10-04 (7) — Отправка журнала на сервер из приложения

- `services/api_sync_service.dart` (`ApiSyncService`, синглтон и ChangeNotifier,
  запускается в main.dart):
  - очередь — события в локальной БД с `synced = 0` (переживает перезапуск);
  - отправка пакетами по 200 через 2 с после нового события и раз в минуту;
  - при ошибке связи повтор через 15 → 30 → 60 → 120 → 300 с;
  - при неверном логине или пароле повтор раз в 30 мин (не упираемся в лимит входа на сервере);
  - токен хранится в settings (`apiToken`, `apiTokenExpires`, `apiTokenFor` = адрес|логин),
    при 401 выполняется повторный вход;
  - 422 — отклонённые события получают `synced = 2`, остальные уходят дальше;
    события старше 360 дней не отправляются.
- БД v7: в `events` добавлены `zoneName`, `place`, `detectorSlot`, `synced`.
  `_addEvent` дополняет событие данными извещателя.
- id события: `миллисекунды-NNN` (раньше два события в одну миллисекунду затирали друг друга).
- Настройки API: строка состояния (связь, не отправлено N, последняя отправка),
  кнопки «Проверить связь» и «Отправить сейчас».
- AndroidManifest: разрешение INTERNET (раньше было только в debug-сборке).
- Формат пакета проверен на тестовом сервере в Docker.

## 2026-10-04 (6) — Серверное API журнала событий (PHP)

- Новая папка `server_api/`: PHP 8.1+, mysqli, JSON. Подробности — `server_api/README.md`.
- Эндпоинты: `GET /ping`, `POST /auth/login`, `POST /auth/logout`,
  `POST /events` (пакет до 500 событий, идемпотентно по `(device, id)`), `GET /events`.
- Безопасность: `password_hash`, токен 256 бит (в БД только SHA-256, срок 30 дней),
  лимит неудачных входов 5 за 15 минут по IP и логину, prepared statements,
  строгая проверка полей, обязательный HTTPS, document root = `public/`.
- CLI `bin/device.php`: add / passwd / disable / enable / revoke / list / cleanup.
- Проверено в Docker (php:8.3 + mysql:8.0): вход, отправка, повторная отправка
  (дубли), ошибки проверки, отзыв токена, лимит попыток, 404/405.
- Отправка событий из приложения ещё не реализована.

## 2026-10-04 (2) — Номера извещателей, правки программирования и журнала

- Экран программирования: квадраты фиксированного размера (160) сразу заполняют
  весь экран. Нажатие на свободный квадрат программирует извещатель в этот номер.
  «+» без рамки в конце добавляет ещё ряд квадратов.
- Номер квадрата закреплён за извещателем (`detectors.slot`, БД v6; при миграции
  существующим извещателям номера раздаются по порядку). После удаления номер
  освобождается, остальные номера не сдвигаются. Главный экран показывает `slot`.
- После инициализации (0x54) тревоги от этого извещателя игнорируются 1 минуту:
  при вставке батареи он сразу шлёт тревогу (`_programmedAt`).
- Журнал: «потеря связи», «поставлен на охрану», «снят с охраны», «тревога
  сброшена», «запрограммирован» пишутся с полной подписью
  `№N МОДЕЛЬ [ID] Зона, место` (`_detectorLabel`).

## 2026-10-04 — Первый запуск, автоподключение BT, программирование извещателей

**Первый запуск**
- Экран выбора языка (пока только «Русский»), затем ввод пин-кода (4–8 цифр,
  с подтверждением). Оба значения сохраняются в `settings` (`language`, `pinCode`).
  Файлы: `screens/onboarding_screen.dart`, `main.dart`, `settings_provider.dart`.

**Bluetooth**
- Выбранное устройство запоминается по id в БД; автопереподключение каждые 10 с
  при любой потере связи (кроме ручного отключения). Состояние адаптера
  отслеживается через `FlutterBluePlus.adapterState`.
- Журнал: BT подключено / потеря связи / отключено вручную / Bluetooth выкл и вкл.
- Потеря связи — короткий звуковой сигнал (`AudioService.playShortBeep`).
- Значок BT на главном экране: синий — есть связь, серый — нет.
- Подписки на характеристики теперь отменяются при переподключении (раньше копились).
- Убрано удаление всех извещателей при каждом подключении.

**Извещатели**
- Настройки → «Программирование извещателей»: сетка квадратных блоков и блок «+»
  (красный, если извещателей нет). «+» → баннер «Вставьте элемент питания в
  извещатель» → ожидание пакета с кодом 0x54 → запись в БД, событие в журнал,
  диалог зоны и места с подсказками по уже введённым значениям.
- Нажатие на извещатель: правка зоны и места, удаление (с подтверждением, событие в журнал).
- Зона теперь текстовое поле извещателя (`detectors.zoneName`, БД v5).
- Пакеты от извещателей, которых нет в БД, игнорируются.
- Тревога: дубли в течение 3 с игнорируются; тревога от снятого с охраны извещателя
  игнорируется полностью.

**Прочее**
- Журнал: низкий заряд батареи планшета (пакет `battery_plus`, пороги 20% и 10%).
- Настройки → «Сбросить данные до заводских установок» (по пин-коду): очистка всей
  БД и возврат к выбору языка.
- Новые `EventType`: detectorAdded, detectorRemoved, btConnected, btLost,
  btManualDisconnect, btAdapterOff, btAdapterOn, tabletBatteryLow.

**Требует проверки на реальном устройстве**: приход 0x54 от извещателя,
автопереподключение после выключения питания концентратора, звук короткого сигнала.
